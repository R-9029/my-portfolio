# Rogue's Portfolio 

自身のスキルや制作実績を紹介するための、Next.jsで構築したポートフォリオサイトです。

## 🌐 成果物 URL
- **GitHub:** https://github.com/R-9029/my-portfolio
- **公開URL:** https://my-portfolio-iota-black-89.vercel.app/

## 🛠️ 使用技術 (Tech Stack)
- **Frontend:** React / Next.js (App Router) / TypeScript
- **Styling:** Tailwind CSS 
- **Development Tools:** VS Code / Git / GitHub

## ✨ 主な機能・こだわりポイント
- **洗練されたダークモードデザイン:** 黒を基調とした、視認性が高くモダンなインターフェース
- **共通コンポーネントの導入:** 各ページへの遷移をスムーズにし、ユーザービリティを向上
- **オリジナルファビコン:** 独自デザインのアイコンを設定し、ブラウザタブでの視認性を確保
  
## 🚀 ローカルでの起動方法

リポジトリをクローンし、以下のコマンドで開発サーバーを起動できます。

```bash
npm install
npm run dev
